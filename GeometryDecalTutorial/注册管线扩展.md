# 渲染模块注册管线扩展
如果你在某个地方（这里假定为BeginPlay）写下如下代码，就相当于把Execute_RenderThread贴到了RenderPostOpaqueExtensions、RenderOverlayExtensions或者RenderPostResolvedSceneColorExtension所在的位置
```
void MyClass::BeginPlay()
{
	const FName RendererModuleName("Renderer");
	IRendererModule* RendererModule = FModuleManager::GetModulePtr<IRendererModule>(RendererModuleName);
	if (RendererModule)
	{
		RendererModule->RegisterPostOpaqueRenderDelegate(FPostOpaqueRenderDelegate::CreateRaw(this, &MyClass::Execute_RenderThread));

		// RendererModule->RegisterOverlayRenderDelegate(/* ... */);

		// GetResolvedSceneColorCallbacks().Add(/* ... */);
	}
}

void MyClass::Execute_RenderThread(FPostOpaqueRenderParameters& Parameters)
{
	// 添加自己的渲染Pass
	...
}
```
## 简单Pass添加
如果想在视口上画个三角形，最终代码可能会是这样
```
#include "PixelShaderUtils.h"

class FMyPixelShader : public FGlobalShader
{
public:
	// 声明全局着色器
	DECLARE_GLOBAL_SHADER(FMyPixelShader);
	
	// 此着色器使用结构作为其参数
	SHADER_USE_PARAMETER_STRUCT(FMyPixelShader, FGlobalShader);
	
	// 着色器参数结构声明
	BEGIN_SHADER_PARAMETER_STRUCT(FParameters, )
		SHADER_PARAMETER_RDG_TEXTURE_SRV(Texture2D, ColorTexture)	// 颜色纹理
		RENDER_TARGET_BINDING_SLOTS()								// 渲染目标绑定槽
	END_SHADER_PARAMETER_STRUCT()
	
public:
	static bool ShouldCompilePermutation(const FGlobalShaderPermutationParameters& Parameters)
	{
		return true;
	}
};
	
// 实现全局着色器				  							  	      
IMPLEMENT_GLOBAL_SHADER(/*着色器类*/FMyPixelShader, /*着色器文件位置*/"/MyModule/MyShader.usf", /*入口函数名*/"MainPixelShader", /*着色器类型*/SF_Pixel);

void MyClass::Execute_RenderThread(FPostOpaqueRenderParameters& Parameters)
{
	// 着色器参数
	FMyPixelShader::FParameters* PassParameters = GraphBuilder.AllocParameters<FMyPixelShader::FParameters>();

	FRDGTextureSRVRef ColorTextureSRV = GraphBuilder.CreateSRV(FRDGTextureSRVDesc::Create(Parameters.ColorTexture));
	PassParameters->ColorTexture = ColorTextureSRV;

	PassParameters->RenderTargets[0] = FRenderTargetBinding(Parameters.ColorTexture, ERenderTargetLoadAction::ELoad);

	// 着色器
	TShaderMapRef<FMyPixelShader> PixelShader(GetGlobalShaderMap(GMaxRHIFeatureLevel));

	// 添加全屏pass
	FPixelShaderUtils::AddFullscreenPass(
		GraphBuilder,
		GetGlobalShaderMap(GMaxRHIFeatureLevel),
		RDG_EVENT_NAME("DrawTriangle"),
		PixelShader,
		PassParameters,
		FIntRect()
	);
}
```
这里有几点要注意：
- IMPLEMENT_GLOBAL_SHADER中的着色器文件位置要求使用虚拟文件路径，需要在该模块的StartupModule函数中添加着色器源文件映射，代码可能如下：
	```
	void FMyModule::StartupModule()
	{
		FString ShaderDirectory = FPaths::Combine(FPaths::ProjectPluginsDir(), TEXT("MyModule/Shaders/Private"));
		AddShaderSourceDirectoryMapping("/MyModule", ShaderDirectory);
	}
	```
- 并且该模块的加载时机需要设置为PostConfigInit，如下：
	```
	"Modules": [
		{
			"Name": "MyModule",
			"Type": "Runtime",
			"LoadingPhase": "PostConfigInit"
		}
	]
	```
